Версия: Java 8 или выше
Система сборки: Не используется. Программа запускается напрямую из исходного кода.
Сторонние библиотеки: Не используются. Программа использует только стандартные библиотеки Java (java.io, java.nio.file,
java.util.regex).

Запуск программы:
1. Компиляция: Перейдите в каталог, содержащий файл FileContentFilter.java и выполните команду для компиляции:
   javac FileContentFilter.java - эта команда создаст файл FileContentFilter.class
!Если вдруг вы не можете найти, в каком каталоге у вас находится FileContentFilter.java, можно воспользоваться командой
find / -name FileContentFilter.java 2>/dev/null!
2. Запуск: Откройте терминал или командную строку, перейдите в каталог, содержащий FileContentFilter.class
   и выполните нужную вам команду. Например, java FileContentFilter <путь_к_файлу1.txt> <путь_к_файлу2.txt> -o
   <путь_к_выходному_каталогу> -p <префикс_для_имен_файлов> -f
